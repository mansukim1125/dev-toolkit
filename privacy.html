1. 기기 내부에서 처리하는 정보

Base64, JSON 정리, 환경변수 변환, JSON/XML 비교, JWT, Cron, 시간대 변환, 이미지 변환, URL 변환은 앱에 포함된 코드로 기기 내부에서 실행됩니다.

  • 텍스트, JSON·XML, 환경변수, JWT 토큰·키, 날짜·시간·Cron 표현식, 이미지와 변환 결과를 앱 운영자의 서버로 전송하거나 별도 데이터베이스에 보관하지 않습니다.
  • 도구를 이동하면 해당 도구의 입력이 초기화됩니다. 운영체제가 앱 프로세스를 유지하는 동안에는 내용이 메모리에 남을 수 있으며, 프로세스가 종료되면 메모리의 내용이 제거됩니다.
  • 사용자가 요청한 경우 결과를 기기 클립보드에 복사하거나, 변환한 이미지를 Android 시스템 저장기로 선택한 위치에 저장합니다. 저장한 결과는 앱 종료 후에도 남으며 사용자가 기기에서 삭제할 수 있습니다.

앱은 사용자가 선택한 파일에 접근하는 시스템 파일 선택기를 사용하며, 광범위한 사진·저장소 접근 권한을 요청하지 않습니다. 결과를 다른 앱에 붙여넣거나 공유한 이후의 처리는 해당 앱과 기기·클립보드 동기화 설정에 따릅니다.

2. 선택 기능인 DNS 조회의 외부 전송

DNS 도구는 화면의 안내를 확인하고 전송에 동의한 뒤 조회를 실행했을 때만 Google Public DNS와 Cloudflare Public DNS에 HTTPS 요청을 보냅니다. DNS 조회를 사용하지 않아도 다른 도구를 이용할 수 있습니다.

제공자에게 전달되거나 통신 과정에서 처리되는 정보는 조회 도메인 이름, DNS 레코드 유형, 요청 IP 주소, 요청 시각 및 HTTP·네트워크 기술 정보입니다. 도메인에 개인정보가 포함될 수 있으므로 내부 도메인이나 민감한 정보를 포함한 이름은 입력하지 마세요.

Google Public DNS · Google LLC

DNS 응답 제공, 서비스 유지·개선, 보안 및 악용 방지, 이용 통계 작성에 정보를 사용합니다. 공식 방침에 따르면 요청 IP와 조회 내용이 포함된 임시 로그는 일반적으로 24~48시간 내 삭제 절차가 적용되며, 보안·악용 문제 대응을 위해 더 오래 보관할 수 있습니다.

일부 로그에서는 IP를 제거하고 도시·지역 수준 정보로 대체해 통계를 작성합니다. 앱이 GPS 위치를 읽는 기능은 없지만, 제공자가 요청 IP로부터 대략적인 지역을 추정할 수 있습니다.

Google Public DNS 개인정보 처리 안내

Cloudflare Public DNS · Cloudflare, Inc.

DNS 응답 제공, 서비스 운영, 네트워크 문제 해결 및 보안을 위해 요청 정보를 처리합니다. 공식 방침은 요청자 식별 정보의 보관·사용을 제한하며, 네트워크 문제 해결·서비스 거부 공격 완화를 위한 소량의 표본 패킷 등 예외를 설명하고 있습니다. 구체적인 로그 항목·보관·삭제 조건은 아래 제공자 방침에서 확인할 수 있습니다.

Cloudflare Public DNS 개인정보 처리 안내

두 제공자의 글로벌 인프라에서 정보가 처리될 수 있으며 처리 위치·보관 조건에는 각 제공자의 정책이 적용됩니다. 앱 운영자는 이 제공자들의 요청 로그를 직접 열람하거나 삭제하는 기능을 갖고 있지 않습니다.

3. 지원 이메일로 문의할 때

mansukim1125@icloud.com으로 문의하면 사용자가 보낸 이메일 주소, 메시지, 자발적으로 첨부한 자료를 문의 확인·답변 및 문제 해결에 사용합니다. 실제 비밀키, 인증 토큰, 비밀번호, 개인정보가 포함된 원본 파일은 보내지 마세요.

4. 계정·광고·분석과 플랫폼의 처리

앱에는 회원가입, 사용자 계정, 광고 및 앱 운영자가 사용하는 별도의 이용자 분석·크래시 수집 SDK가 없습니다. 앱은 광고 ID나 설치 식별자를 직접 수집하지 않습니다.

Android와 Google Play 자체의 설치·진단 정보 처리는 운영체제, 계정 설정 및 각 플랫폼의 정책에 따릅니다. 이 방침 페이지를 제공하는 웹서버·호스팅 서비스도 페이지 전송과 보안을 위해 IP 주소 등 기본 접속 정보를 처리할 수 있습니다.

5. 보호, 선택 및 삭제 방법

  • 앱의 외부 DNS 요청에는 HTTPS를 사용합니다. 해당 정보가 앱의 평문 HTTP 연결로 전송되지 않도록 구성합니다.
  • DNS 전송에 동의하지 않거나 조회를 실행하지 않으면 DNS 요청이 전송되지 않습니다. 동의 여부는 DNS 도구 화면을 다시 열 때 초기화됩니다.
  • 입력 중인 내용은 초기화하거나 도구를 이동해 지울 수 있습니다. 사용자가 저장한 이미지·클립보드 내용은 기기에서 관리해 주세요.
  • 앱에는 운영자 서버의 사용자 계정·입력 데이터베이스가 없어 계정 삭제 기능이 없습니다. DNS 제공자의 로그를 앱에서 삭제하는 기능도 제공하지 않습니다.

개인정보 처리에 관한 열람·정정·삭제·처리 중지 등의 문의는 아래 연락처로 보내 주세요. 운영자가 실제로 보유·관리하는 정보에 대해 요청을 확인하고 가능한 조치와 처리 범위를 안내합니다. DNS 제공자나 메일 서비스가 관리하는 정보에는 해당 제공자의 절차가 적용됩니다.
